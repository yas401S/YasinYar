# یاسین‌یار — همراه یادگیری پایه‌های اول تا نهم

این مخزن پروژه مستقل اندروید یاسین‌یار است. رابط برنامه فارسی و راست‌چین است و محتوای نمونه را بدون اینترنت نمایش می‌دهد.

## وضعیت فعلی
- پوسته اولیه برنامه اندروید با WebView
- انتخاب پایه‌های اول تا نهم و فهرست اولیه درس‌ها
- نمونه سؤال تألیفی ریاضی ششم با پاسخ مرحله‌ای
- نگهداری ساده پیشرفت روی دستگاه
- گردش‌کار GitHub Actions برای ساخت APK آزمایشی

## ساخت APK
1. وارد زبانه Actions مخزن شوید.
2. گردش‌کار **Build YasinYar APK** را انتخاب کنید.
3. پس از پایان موفق، در بخش Artifacts فایل **YasinYar-debug-apk** را دریافت کنید.

## نکته مهم درباره محتوا
سؤال نمونه با برچسب `original_practice` تألیفی است و سؤال رسمی کتاب درسی نیست. پاسخ تمرین‌های رسمی فقط پس از تطبیق با متن کتاب و چاپ/سال تحصیلی مربوط اضافه می‌شود. فهرست درس‌ها نیز فعلاً اولیه است.

## ساختار
- `app/`: برنامه اندروید و رابط وب آفلاین
- `data/questions.json`: قالب بانک سؤال
- `.github/workflows/build-apk.yml`: ساخت خودکار APK

شناسه برنامه: `ir.yasinyar.app`
